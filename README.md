# lazyweb

Небольшой Flask-сервер, который читает папку `content/` с markdown-файлами
и показывает её как сайт: список папок, страницы заметок, подсветка кода.

Редизайн и доработка [vintdime/coolserver](https://github.com/vintdime/coolserver).

## Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Откроется на <http://127.0.0.1:8000>.

## Как устроено

```
main.py            маршруты, разбор markdown, обход content/, WSGI-приложение
content/           сами заметки (.md и исходники)
templates/         Jinja-шаблоны
static/css/        одна таблица стилей
vercel.json        сборка main.py и маршрут всех путей в приложение
```

## Деплой

Развёрнуто на Vercel: <https://lazywebremake.vercel.app>. Пуш в `main`
пересобирает деплой автоматически.

Два места, где Vercel ведёт себя не как локальный сервер, и это учтено
в конфиге и коде:

- `rewrites` подменяют путь, и приложение видит `/api/index` вместо
  запрошенного URL. Поэтому в `vercel.json` используются `builds`+`routes`;
- Python-рантайм не раскодирует `PATH_INFO`, хотя WSGI это предполагает.
  Middleware в `main.py` чинит это — только на Vercel, локально путь
  приходит уже раскодированным.

## Разбор markdown

Поверх Python-Markdown включено:

- `extra` — таблицы, ```-блоки, сноски, списки определений;
- `nl2br` — перенос строки остаётся переносом, как в Obsidian;
- `sane_lists`, `admonition`, `codehilite` (Pygments), `toc`.

Плюс две правки под то, как реально написаны конспекты:

- отключён блок кода по отступу — строки вида `      ↓` остаются текстом,
  а не превращаются в серый блок (```-блоки работают как обычно);
- `  # Заголовок` с отступом до трёх пробелов распознаётся как заголовок,
  и якоря заголовков сохраняют кириллицу.

## Что показывается

`.md` рендерятся как заметки. Файлы с исходниками (`.py`, `.cpp`, `.html`
и другие) открываются с подсветкой — раньше они лежали в `content/`,
но на сайт не попадали. Скрытые файлы и всё за пределами `content/`
отдают 404.
